# 2026 의령 리치리치 행사장 지도 좌표

## 2026-10-01 적용: 솥바위 왼쪽 위 지도 (앱 0.2.4)

아래의 원본/PPT 좌표 설명은 이전 지도 기록이다. 현재 앱은 승인된
`richrich_map_sotbawi_top_left.png` 일러스트를 사용한다. 솥바위 별도 구역은
왼쪽 위, 본 행사장은 오른쪽 아래에 있으며 좌표는 이미지 전체의 백분율이다.
실측 GPS가 아닌 일러스트 기준 근사 좌표이므로 현장 확인 후 보정한다.

- 새 앱 요청: `map_layout_id: sotbawi-top-left-v2`
- 좌표 원본: 두 프로젝트 JSON의 `rich_flow.map_layouts.sotbawi-top-left-v2.markers`
- 구버전 앱(식별자 없음) 및 알 수 없는 식별자: 기존 `venue_operations[].marker` 유지
- A/B 현재 위치: 동일 레이아웃의 `CONDITION_A`, `CONDITION_B`; 앱에 번들된 설정 사용
- 추천 장소 좌표: 서버 응답 사용. 이후 장소 좌표 보정은 해당 레이아웃 설정으로 수행
- 배경 이미지 또는 현재 위치의 추가 변경은 APK 업데이트 필요
- A/B 추천중지는 운영 DB 설정이며 이 지도 변경으로 해제하지 않는다.

결과 화면은 진입 후 20초가 지나면 지도로 자동 이동한다. 지도 버튼을 누르면
즉시 이동하며, 버튼과 타이머의 중복 이동을 방지한다. 화면을 떠나면 타이머는
취소된다. 지도 화면의 기존 15초 후 처음 화면 복귀는 유지한다.

정식 배포는 기존 전용 서명키로 `apps/android/build-distribution.ps1`을 실행한 후
GitHub Release에 `recommendation-android.apk`라는 이름으로 올린다.
새 키를 만들거나 디버그 APK로 정식 배포물을 대체하지 않는다.

## 좌표 기준

- 이미지 왼쪽 위: `(0, 0)`
- 이미지 오른쪽 아래: `(100, 100)`
- `x_percent = 원본 x / 1670 × 100`
- `y_percent = 원본 y / 942 × 100`
- 지도 비율을 유지한 상태에서 핀과 경로를 동일한 비율 좌표로 그린다.
- 아래 좌표는 지도에 표시된 영역 또는 라벨의 중심 근사치다. 현장 설치 위치와 프로그램별 정확한 핀은 담당자 확인 후 보정한다.

## 구현 원칙

1. 기획서 이미지에 포함된 기존 텍스트 라벨은 배경으로 유지한다.
2. 앱은 현재 위치, 추천 순번 1·2·3, 선택된 장소 라벨과 점선 경로만 오버레이한다.
3. 각 키오스크는 자신의 `marker`를 현재 위치로 사용한다.
4. `PENDING_CONFIRMATION` 좌표는 관리자 화면에서 조정할 수 있도록 한다.
5. 정거장 사이 경로는 우선 직선 또는 완만한 보간 경로로 표시하고, 실제 보행로 좌표가 오면 경유점 배열로 교체한다.
