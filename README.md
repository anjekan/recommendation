# 범용 감정 분석·콘텐츠 추천 플랫폼

이 저장소는 태안 꽃박람회용 Android 키오스크를 출발점으로, 여러 행사와 콘텐츠에 재사용할 수 있는 범용 감정 분석·장소 추천 플랫폼을 설계하고 구현하기 위한 작업 공간이다.

현재 우선 개발 대상은 Android 클라이언트다. 그러나 시스템은 Android 앱 하나에 종속하지 않고 향후 Web/PWA 클라이언트가 동일한 계약과 데이터를 사용할 수 있도록 설계한다.

## 핵심 목표

- 카메라 기반 감정·생체 신호 분석
- 감정 상태에 따른 콘텐츠와 장소 추천
- 같은 장소의 연속 추천 방지
- 여러 태블릿의 추천량을 고려한 동선 분산
- 서버 없이 동작하는 LOCAL 모드
- 서버를 사용하는 REMOTE 모드
- 서버 장애 시 로컬로 전환되는 HYBRID 모드
- 집행부가 실시간 현황과 장소 상태를 확인·제어하는 관리자 웹
- 꽃·정원·태안 같은 전용 데이터를 코드에서 분리
- 프로젝트 설정만 교체해 다른 행사에 재사용

기존 프로젝트는 빌드에 성공했지만 UI, 분석, 서버 통신, 추천, 다국어, 지도 로직이 Activity와 WebView에 강하게 결합되어 있다. 신규 프로젝트를 중심으로 구축하고 기존 분석 모델과 알고리즘을 선별 이식하는 방향을 우선한다.

## 최상위 원칙

1. 기능 구현보다 시스템 경계와 유지보수성을 우선한다.
2. 도메인에는 Android, Retrofit, Room 등 기술 타입을 노출하지 않는다.
3. 서버와 클라이언트는 공통 요청·응답 계약을 사용한다.
4. 서버가 없어도 클라이언트 단독으로 전체 사용자 흐름이 동작해야 한다.
5. PostgreSQL을 서버 데이터 원본으로 사용한다.
6. Android는 Room/SQLite를 설정 캐시와 오프라인 이력에 사용한다.
7. Redis는 대규모 실시간 추천 상태 계층으로 설계하되 단계적으로 활성화한다.
8. 모든 추천 결과에는 정책 버전과 판단 근거를 남긴다.
9. 개인정보를 수집하지 않고 익명 세션과 UUID를 사용한다.
10. UI는 실제 렌더링과 실기기 검증 없이 완료 처리하지 않는다.
