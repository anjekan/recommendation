# Architecture Decision Records

ADR은 이미 결정된 아키텍처 선택과 이유, 결과를 기록한다.

상태:

- Proposed
- Accepted
- Superseded
- Rejected

새 ADR은 이전 결정을 덮어쓰지 않고 `Superseded by ADR-XXXX`로 연결한다.
