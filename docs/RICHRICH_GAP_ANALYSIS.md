# 2026 의령 리치리치 페스티벌 구현 차이 분석

기준 문서: `RICH_FLOW_디자인_기획서_태블릿_v1.4.pptx` 23장

## 확정된 목표 흐름

1. 개인정보 입력 없이 바로 시작
2. 전면 카메라 10초 비접촉 측정
3. 스트레스 지수 4단계와 AU 얼굴 긴장도 3구간으로 12상태 판정
4. 12상태를 안목·향기·미식·경청·실천·통찰 중 오늘의 감각으로 변환
5. 서로 다른 행사 구역에 있는 3정거장 코스 추천
6. 부자의 나침반 결과를 5초 표시한 뒤 행사장 지도로 자동 이동
7. 현재 위치와 1·2·3정거장, 점선 경로 표시
8. 얼굴 미검출 5초 후 시작 화면 복귀

## 데이터 모델 확장안

- `project`: `UIRYEONG_RICHRICH_2026`, 행사 기간과 운영시간
- `sense`: 안목·향기·미식·경청·실천·통찰
- `condition_state`: 12상태, 판정군, 출력 문구, 나침반 축 값
- `journey_mapping`: 상태별 1·2·3정거장 감각 순서
- `venue`: 존 번호, 지도 좌표, 수용인원, 유효시간, 실내외, 연령 조건
- `program_schedule`: 운영일, 회차, 시작·종료, 정원, 마감 상태
- `kiosk`: 설치 지점, 현재 위치 좌표, 컨디션존 구분
- `journey_recommendation`: 추천 코스와 1정거장 혼잡 이벤트
- `operation_context`: 현재 시각, 우천 여부, 동반 유형, 공연 시간 창

## 미확정 값 처리

미확정 값은 코드에 고정하지 않고 프로젝트 설정의 `PENDING_CONFIRMATION` 상태로 둔다. 필수값이 비어 있는 장소는 추천 후보에서 제외하고 관리자 화면에 경고한다.

- AU 결합 산식과 3구간 경계값
- E3 과열 기준
- 장소별 수용인원
- 일부 장소의 존 번호와 지도 좌표
- 쉼터 위치
- 프로그램별 운영시간·회차·정원
- 방문 유형 입력 여부

## 구현 순서

1. 의령 프로젝트 설정 스키마와 기본 데이터 생성
2. 기획서의 2026 지도 이미지 추출 및 좌표 체계 정의
3. 12상태·6감각·3정거장 도메인과 API 계약 확장
4. 서버 추천·혼잡·일정 필터 구현
5. 시작·측정·나침반·여정 지도 화면 구현
6. 관리자 감각·상태·혼잡·키오스크 집계 확장
7. 리허설 값 반영과 30대 단말 설정 생성

## 주의 사항

- 제공된 별도 지도 스크린샷은 2025 행사 지도이므로 구현 기준으로 사용하지 않는다.
- 지도 화면은 기획서 007에 사용된 2026 배치도를 기준으로 한다.
- 기존 태안 프로젝트와 API 호환성을 유지하며 의령 기능은 새 스키마 버전으로 추가한다.
- 현재 미커밋 상태인 실제 카메라 스캔선 변경은 유지한다.
