# Admin Web

집행부와 운영자가 사용하는 프로젝트 관리 및 실시간 상황판이다.

## 현재 구현

관리자 대시보드는 별도 Node 프로세스 없이 Spring Boot의 정적 리소스로 제공한다.

```text
http://127.0.0.1:8080/admin/index.html
```

- 전체 추천 건수
- 개인정보 활용 동의·미동의·미선택 집계와 동의율
- 평균 스트레스
- 감정별 추천 건수
- 프로젝트에 등록된 전체 추천 장소와 선택일 장소별 건수·비율·상태
- 최근 추천 20건
- 30초 자동 갱신
- 모바일 대응 반응형 레이아웃

동의 사용자의 이름과 입력 정보가 있으면 최근 추천에 표시하고 전화번호는 마스킹한다. 얼굴 사진은 저장하거나 표시하지 않는다.

관리자 화면과 API는 Spring Security 인증으로 보호한다. 운영 배포 전 초기 비밀번호를 변경하고 HTTPS를 추가해야 한다.

## 후속 범위

- 프로젝트·콘텐츠·장소 관리
- 지도와 마커 좌표 관리
- 감정별 추천 후보 및 가중치 관리
- 장소 정상·혼잡·추천 중지 설정
- 태블릿 연결 상태
- 기간·시간대별 추천 현황과 CSV 내보내기
- 변경 감사 이력

화면 규모가 커지면 별도 프론트엔드 프레임워크 도입 여부를 ADR로 결정한다.
