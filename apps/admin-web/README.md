# Admin Web

집행부와 운영자가 사용하는 프로젝트 관리 및 실시간 상황판이다.

## 현재 구현

관리자 대시보드는 별도 Node 프로세스 없이 Spring Boot의 정적 리소스로 제공한다.

```text
http://127.0.0.1:8080/admin/index.html
```

- 전체 추천 건수
- 개인정보 활용 동의·미동의·미선택 집계와 동의율
- 평균 스트레스
- 감정별 추천 건수
- 최근 추천 20건
- 30초 자동 갱신
- 모바일 대응 반응형 레이아웃

대시보드에는 이름, 전화번호, 얼굴 사진을 표시하거나 저장하지 않는다. 익명 세션에 연결된 동의 상태만 통계로 사용한다.

현재 화면은 로컬·사무실망 개발용이며 인증이 없다. 인터넷에 직접 공개하지 말고, 운영 배포 전에 관리자 인증·권한과 HTTPS를 추가해야 한다.

## 후속 범위

- 프로젝트·콘텐츠·장소 관리
- 지도와 마커 좌표 관리
- 감정별 추천 후보 및 가중치 관리
- 장소 정상·혼잡·추천 중지 설정
- 태블릿 연결 상태
- 기간·장소·시간대별 추천 현황과 CSV 내보내기
- 변경 감사 이력

화면 규모가 커지면 별도 프론트엔드 프레임워크 도입 여부를 ADR로 결정한다.
